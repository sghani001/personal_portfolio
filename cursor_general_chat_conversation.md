These are **production build artifacts** — the compiled, minified files Vite outputs when you run `npm run build`. They are what actually gets served when the site is deployed (e.g. to GitHub Pages via `gh-pages -d dist`).

## What each file does

### `index-ib5hWT1C.css` (the CSS you pasted)
This is your **compiled stylesheet**. It comes from `src/index.css` and includes:

- **Google Fonts** — Space Grotesk, Inter, JetBrains Mono
- **Tailwind CSS** — base reset, utilities (`.flex`, `.grid`, `.hidden`, etc.)
- **Your theme** — CSS variables like `--bg`, `--primary`, dark/light mode (`.light`)
- **Custom layout classes** — `.hero-grid`, `.rails-grid`, `.about-grid`, `.nav-links`
- **Animations** — `@keyframes pulse`, `fadeUp`

The long minified blob is normal — Vite + Tailwind collapse everything into one file for faster loading.

### `index-D9xyDNWk.js`
This is your **bundled JavaScript** — your entire React app (`App.jsx`, components, logic) compiled into one file. The browser loads it, mounts React into `<div id="root">`, and renders the portfolio.

## How they connect

`dist/index.html` links both:

```32:33:g:\projects\Ghani\personal_portfolio\dist\index.html
    <script type="module" crossorigin src="/assets/index-D9xyDNWk.js"></script>
    <link rel="stylesheet" crossorigin href="/assets/index-ib5hWT1C.css">
```

## Why the random hash in the filename?

`D9xyDNWk` and `ib5hWT1C` are **content hashes**. When you change source code and rebuild, Vite generates new filenames so browsers fetch fresh files instead of using cached old ones.
